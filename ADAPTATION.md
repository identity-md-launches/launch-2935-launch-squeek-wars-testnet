# Sepolia size adaptation

The five-contract launch is prepared with **51,368 runtime bytes**, down from **61,682** (10,314 bytes saved). The local factory rehearsal estimates **89,870,111 gas** under the brief's approximately 1,700-gas-per-runtime-byte assumption, including calldata and a 500,000-gas factory allowance. The calculation and commands are in [docs/VALIDATION.md](docs/VALIDATION.md).

`foundry.toml` and all dependencies are unchanged: Solidity 0.8.26, Cancun, optimizer 200 runs, via IR, no bytecode metadata hash. The existing `launch.json` is byte-for-byte unchanged. It still deploys GameRules → SeedLedger → Clans → Army → Villages, uses `$owner` for the paying wallet, and preserves Core `0x980b4424c007caf7a1f3670b48c8eaef7ebc3d44` and NFT `0xcb98349c134ab983da5bfd80527dfe2552bdb70f`. There is no token, pool, new deployment, new dependency, or post-constructor wiring step. This source task did not broadcast transactions.
